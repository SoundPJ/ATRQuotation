# ATIRUJ — ใบเสนอราคา (Quotation Generator)
ระบบสร้างใบเสนอราคา 100% client-side สำหรับ deploy บน GitHub Pages
https://soundpj.github.io/ATRQuotation/

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าฟอร์มทั้งหมด (UI) |
| `app.js` | Logic ทั้งหมด: DBD fetch, จัดการรายการสินค้า/รูปภาพ, สร้าง PDF |

ไม่มี backend, ไม่มี build step — เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือ push ทั้งสองไฟล์ขึ้น GitHub repo แล้วเปิด GitHub Pages

---

## วิธี Deploy บน GitHub Pages

1. สร้าง repository ใหม่ (หรือใช้ของเดิม)
2. อัปโหลด `index.html` และ `app.js` ไว้ที่ root (หรือโฟลเดอร์ `/docs`)
3. ไปที่ **Settings → Pages**
4. เลือก branch ที่ต้องการ (เช่น `main`) และโฟลเดอร์ (`/` หรือ `/docs`)
5. กด **Save** — รอ 1-2 นาที แล้วเข้าใช้งานที่ `https://<username>.github.io/<repo>/`

## การทำงานของแต่ละส่วน

### 1. ดึงข้อมูลจาก DBD OpenAPI
ระบบยิง request ตรงจาก browser ผู้ใช้ไปที่:
```
https://openapi.dbd.go.th/api/v1/juristic_person/{เลขนิติบุคคล 13 หลัก}
```
**ข้อดี:** แต่ละคนยิง API จาก IP ของตัวเอง ไม่ติด rate limit รวมจากการรันบน server กลางแบบ Apps Script

**ถ้าเจอปัญหา CORS:** DBD บางครั้งไม่ได้เปิด CORS header ให้ ถ้าเจอ error "เชื่อมต่อ DBD ไม่ได้" ให้:
1. คลิก "⚙ ตั้งค่า CORS Proxy" ใต้ช่องค้นหา
2. กรอก URL ของ CORS proxy เช่น `https://corsproxy.io/?url=`
3. ติ๊กถูก "ใช้ Proxy นี้" แล้วลองดึงข้อมูลใหม่

**เลข ID สำหรับทดสอบ:** `0107567000414` — ถ้า DBD จริงเอื้อมไม่ถึง (เช่นทดสอบแบบ offline) ระบบจะ auto-fallback เป็นข้อมูลจำลองที่มีรูปแบบเดียวกับ DBD จริงทุกฟิลด์ เพื่อให้ทดสอบ flow การทำงานได้ครบ

### 2. รูปภาพสินค้า
- คลิกไอคอน 🖼 ในแต่ละแถวเพื่อเลือกไฟล์รูป
- รูปจะถูกอ่านเป็น base64 เก็บใน memory (ไม่อัปโหลดไปไหน — ทุกอย่างอยู่ใน browser)
- เมื่อ export PDF ระบบจะคำนวณอัตราส่วนภาพจริงและคงสัดส่วนเสมอ (ไม่บีบ/ยืดให้ภาพเสีย) โดยจำกัดไม่เกิน 34×34pt ในตาราง

### 3. เลขที่เอกสาร
กรอกแค่เลขลำดับ (เช่น `1`) ระบบจะแปลงเป็น `Q6906-01` อัตโนมัติ โดย:
- `69` = ปี พ.ศ. 2 หลักสุดท้าย (จากปี 2569)
- `06` = เดือน (มิถุนายน)
- `01` = เลขลำดับที่กรอก (เติม 0 ข้างหน้าให้ครบ 2 หลัก)

คำนวณจากวันที่ในช่อง "วันที่ออกเอกสาร" — เปลี่ยนวันที่แล้วเลขที่จะอัปเดตอัตโนมัติ

### 4. PDF Export — ฟอนต์ภาษาไทย
ใช้ **pdf-lib + @pdf-lib/fontkit** โหลดฟอนต์ Sarabun จาก Google Fonts ที่ runtime (ไม่ต้อง base64 ฝังในโค้ด เพราะ Google อาจเปลี่ยน URL ฟอนต์เวอร์ชันใหม่ได้ ระบบจะ parse CSS response เพื่อหา URL ล่าสุดเสมอ)

**ปัญหาสระลอย/วรรณยุกต์ลอยที่พบบ่อยใน pdf-lib:** ปกติ `pdf-lib`'s `drawText()` ไม่รองรับ OpenType shaping (GSUB/GPOS) ทำให้สระและวรรณยุกต์ไทยวางตำแหน่งผิด ระบบนี้แก้ปัญหาด้วยการ:
1. เรียก `fontkit`'s `font.layout()` ตรงเพื่อให้ได้ตำแหน่ง glyph ที่ shape ถูกต้องตาม GPOS ของฟอนต์
2. วาดแต่ละ glyph เป็น vector path ด้วย `page.drawSvgPath()` ที่ตำแหน่งจริง
3. วาด invisible text layer ทับด้วย `drawText()` ปกติ (opacity 0) เพื่อให้ยัง copy-paste ได้ และมี ToUnicode mapping ที่ถูกต้อง — ข้อความจะไม่กลายเป็นตัวอักษรประหลาดเมื่อ copy ไปวางที่อื่น

## Known Limitations
- DBD OpenAPI ไม่ได้รับประกันว่าจะเปิด CORS เสมอ — ถ้าติดปัญหาบ่อย ให้ตั้งค่า CORS Proxy ของตัวเอง (เช่น deploy Cloudflare Worker เป็น proxy แทนการพึ่ง public proxy)
- ฟอนต์ Sarabun โหลดจาก Google Fonts ทุกครั้งที่กด "สร้าง PDF" (มี cache ในหน่วยความจำระหว่าง session เดียวกัน) — ต้องมีอินเทอร์เน็ตตอนสร้าง PDF
- ระบบไม่มีการบันทึกข้อมูลถาวร (ไม่มี database) — ปิดหน้าเว็บแล้วข้อมูลในฟอร์มจะหายไป ถ้าต้องการบันทึกประวัติใบเสนอราคา ต้องเพิ่มระบบ storage แยกต่างหาก
